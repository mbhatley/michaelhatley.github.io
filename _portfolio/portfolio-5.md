### About

**Note: this package is still undergoing sandbox testing and development. Target publication is September 2026**

A Python library for modeling spatial point patterns - scattered (x, y) locations in a 2D region - as realizations of a Poisson process whose intensity is shaped by a finite mixture of bivariate normal components. It provides the data model, Bayesian MCMC fitting (both a fixed and an automatically-selected number of mixture components), simulation and fitting for point-interaction (Gibbs/Markov) processes, self-exciting (Hawkes) event streams, marked point patterns, and matplotlib-based plotting for all of the above.
